# Web Robots Kickstarter datasets

- URL: https://webrobots.io/kickstarter-datasets/
- Fetch date: 2026-09-03
- Publisher: Web Robots

Excerpt/notes used: Web Robots says its robot collects Kickstarter project data in CSV and JSON and has run monthly from March 2016. The newest listed snapshot was 2026-08-12; the baseline chosen here is 2023-12-14. It warns that archives are compressed and large. More importantly, it says Kickstarter began limiting how many projects can be viewed in one category in April 2015, so a scrape can miss historic projects; recent and active projects are included. It also warns that the post-December-2015 subcategory collection can duplicate a project across categories. Timestamps are Unix time.

Direct archive URLs and MD5 checksums are recorded in `resources/data/README.md`.
