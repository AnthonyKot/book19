# Exchange rate used for the local-equivalent screen

- URL: https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html
- Fetch date: 2026-09-03
- Publisher: European Central Bank

The ECB reference table for 2026-09-02 quotes one euro as USD 1.1578 and JPY 184.78. This research therefore converts Japanese yen to reference US dollars as `JPY / 184.78 × 1.1578`; the USD 250,000 screen corresponds to JPY 39,898,946 after rounding to the nearest yen. The reference rate is a reproducible screening convention, not a claim about the exchange rate on each campaign's closing date.
